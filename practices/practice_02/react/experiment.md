# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Цель: найти несогласованности в tests_load.md после всех правок и предложить точечные изменения без добавления разделов
- Доступные входы: [tests_load.md](../../practice_01/tests_load.md), [problem.md](../../practice_01/problem.md)
- Разрешённые действия: читать эти файлы; сравнивать формулировки; предлагать правки существующих строк таблицы
- Запрещённые действия: добавлять новые разделы; менять структуру таблицы; ссылаться на внешние источники
- Максимальное число шагов: 4
- Условие остановки и вопроса человеку: остановиться, если выявлены и предложены все найденные несоответствия или для правок требуется выбор порогов — спросить, какие пороги предпочесть

Проанализируй tests_load.md на согласованность: единицы измерения, определения метрик, унификация подтверждений, ссылки. Сопоставь с целями из problem.md. Верни до трёх точечных правок существующих строк таблицы, если найдёшь несогласованности. Не добавляй разделов.
