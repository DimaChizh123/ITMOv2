**Краткий ответ:** Нет, подписки **не сохраняются** после полного перезапуска программы (нового запуска интерпретатора Python), так как глобальные переменные Python инициализируются заново в каждой сессии. Однако они **сохраняются** между вызовами функций в рамках одного запуска.

**Доказательство на основе кода:**

1. В файле `/mnt/c/Users/dmitk/Desktop/Programming/AI/ITMOv2/practices/practice_03/lab/demo/service.py` строка 1 показывает объявление глобальной переменной:
   ```python
   subscribers = set()
   ```
   
2. Эта переменная определена **в начале модуля**, а не внутри функции `subscribe()`. 

3. При перезапуске Python-программы (например, через консоль с новой командой) создается **новый интерпретатор**, который загружает этот файл заново. В результате:
   - Глобальная переменная `subscribers` инициализируется заново по строке 1 со значением пустого множества `{}`.
   - Подписки, добавленные в предыдущем запуске, будут потеряны.

4. Если бы вы объявили переменную внутри функции (например):
   ```python
   def subscribe(name):
       global subscribers  # Это было бы необходимо, если бы мы не указывали global явно в модуле
       ...
   ```
   то подписки всё равно сохранились бы **только пока запущен один процесс**, но не после перезапуска.

| Тип "перезапуска" | Сохраняются ли подписки? |
|-------------------|-------------------------|
| Новый вызов `subscribe()` внутри одного запуска | **Да**, если используется модуль или класс с состоянием |
| Полный перезапуск программы (новый интерпретатор) | **Нет**, переменная инициализируется заново |
