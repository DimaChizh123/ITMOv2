# Отчёт 1. Атаки на исходный сервис

Описание уязвимостей и воспроизведение атак на исходном сервисе.

1. Инъекции SQL через параметры `GET /profile?id=` и `GET /search?q=`. Используется f-string без параметров, позволяет читать произвольные профили и проводить LIKE-инъекции.
2. Ошибочная аутентификация/авторизация: сервер доверяет заголовку `X-Role` в `GET /admin/export`, позволяя любому клиенту выдать себя за сотрудника.
3. Несоблюдение принципа владения: `GET /orders` возвращает все заказы для любого залогиненного клиента; `GET /files` позволяет читать произвольные пути внутри песочницы по параметрам `user` и `path`.
4. XSS: `GET /reviews/view` рендерит пользовательский текст без экранирования в HTML, что позволяет внедрить скрипт.
5. Эскалация через инструменты помощника: `POST /assistant/execute` позволяет читать любые файлы в песочнице (`read_file`), экспортировать профили без проверки роли (`export_profiles`) и удалять произвольные деревья в песочнице (`delete_tree`), включая чужие данные.
6. Манипуляция ценой: `POST /orders` принимает цену из клиента, позволяя купить товар по произвольной цене.
7. Утечка логов: `GET /debug/logs` открыт всем, включая незалогиненных, содержит чувствительные заголовки и тела запросов.

Воспроизведение ключевых атак:

1. SQL-инъекция профиля: `GET /profile?id=2` от alice возвращает профиль bob; а также возможно составить `id = 1 OR 1=1`.
2. Присвоение роли: добавить `X-Role: staff` и получить экспорт профилей.
3. Чтение чужого чека: `GET /files?user=bob&path=receipt.txt` вернёт чек bob; чтение приватной заметки: `GET /files?user=alice&path=../../private/operator-note.txt` — в исходном сервисе тоже допустимо при обходе путей внутри песочницы (песочница блокирует выход наружу, но `service.py` разрешает доступ к приватным файлам).
4. XSS: отправить отзыв с `<script>alert(1)</script>` и увидеть выполнение на странице отзывов.
5. Инструменты: от лица клиента выполнить `export_profiles` и получить профили; выполнить `delete_tree` с `path: '.'` и удалить все файлы песочницы.
6. Цена: создать заказ с `{"product":"lamp","price":1}` и купить лампу за 1 рубль.
7. Логи: получить полный журнал через `GET /debug/logs`.
