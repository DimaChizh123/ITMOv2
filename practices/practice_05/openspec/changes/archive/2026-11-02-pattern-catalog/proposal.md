# Proposal

## Why

Добавить справочник паттернов для подсказок судоку, чтобы пользователи могли получать теоретическую справку по техникам, которые возвращает `sudoku.hint`. Это снизит порог входа и поможет объяснять найденные техники без изменения текущего поведения подсказчика.

## What Changes

- Добавление нового MCP tool `sudoku.patterns`, возвращающего теоретическую справку по поддерживаемым техникам.
- Поддержка двух режимов: список всех техник (без фильтра) и подробная карточка по конкретной технике (`args.pattern`).
- Единый формат ответа: описание (на русском с англ. названием в скобках), уровень сложности (Базовый/Средний/Продвинутый), структура (JSON-объект), мини-пример (9×9 матрица с выделением ключевых клеток).
- Сообщение для неизвестного tool обобщено на множество инструментов.
- Поведение `sudoku.hint` сохраняется без изменений.

## Capabilities

### New Capabilities
- `mcp/sudoku/pattern-catalog`: Каталог техник судоку, синхронизированный с типами, которые возвращает `sudoku.hint` (кроме `none`). Возвращает список идентификаторов и детализированные карточки по запросу.

### Modified Capabilities

—

## Impact

- Файл `mcp/sudoku/index.py`: добавление ветки обработки `tool == "sudoku.patterns"`, статического реестра техник и унификации сообщения об неизвестном tool.
- Скрипт `scripts/verify.py`: добавление smoke-тестов для `sudoku.patterns` (список, конкретный паттерн, неизвестный паттерн), без изменения существующих тестов `sudoku.hint`.
- Документы/правила: поведение ошибок входных данных остаётся строгим; новые поля возвращаются только в новом tool.
- AGENTS.md: обновить политику объяснений и примеры для sudoku.patterns.
