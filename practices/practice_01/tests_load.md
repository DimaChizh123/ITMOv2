# Нагрузочные проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

| Сценарий | Нагрузка и длительность | Допустимый предел | Что измеряем | Подтверждение |
|---|---|---|---|---|
| Серия ревью по diff | 50 последовательных запросов к /api/reviews | p95 < 1500 мс; error rate < 1%; timeout rate < 1% | p95 по всем 50 запросам; error rate = доля ответов HTTP ≥ 400; timeout rate = доля запросов с t_resp > 5000 мс | Отчёт k6/эквивалента |
| Smoke | 1 RPS; прогрев 30 с, основная фаза 1 мин | p95 < 800 мс; error rate < 1%; timeout rate < 1% | p95 по основной фазе; error rate = доля ответов HTTP ≥ 400; timeout rate = доля запросов с t_resp > 5000 мс | Отчёт k6/эквивалента |
| Stress | Прогрев 1 мин; ступенчатый рост 1→5 RPS, шаг 1 RPS каждые 30 с до 5 мин | p95 < 1500 мс; error rate < 2%; timeout rate < 1% | p95 на пике нагрузки; error rate = доля ответов HTTP ≥ 400; timeout rate = доля запросов с t_resp > 5000 мс | Отчёт k6/эквивалента |
| Soak | 2 RPS; основная фаза 20 мин | p95 < 1200 мс; error rate < 1%; timeout rate < 1% | p95 по основной фазе; error rate = доля ответов HTTP ≥ 400; timeout rate = доля запросов с t_resp > 5000 мс | Отчёт k6/эквивалента |

Если нагрузочное тестирование пока не требуется, объясните это OpenCode. Попросите записать причину и условие, при котором оно понадобится.

Пороги p95 согласованы с целью сокращения времени первичного ревью из [problem.md](problem.md) (−20–30%).
